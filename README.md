# P&L and Balance Sheet Analysis

## Project Overview

This SQL project demonstrates how financial statement reporting can be generated from General Ledger data.

The project includes SQL queries used to prepare:

- Profit & Loss (P&L) Statement
- Balance Sheet

## Files

### pnl.sql
Generates Profit & Loss reporting by aggregating revenue and expense accounts.

### balance_sheet.sql
Generates Balance Sheet reporting by classifying accounts into Assets, Liabilities, and Equity.

## Skills Demonstrated

- SQL Query Writing
- Data Aggregation
- Financial Reporting
- General Ledger Analysis
- Balance Sheet Preparation
- Profit & Loss Analysis

## Business Value



Financial statement reporting supports management decision-making by providing visibility into profitability, financial position, and performance trends.
